# Empathie Energy Accounting v0.4.0

This is the first version that can update itself. It checks GitHub Releases on
launch and offers the new APK inside the app, so future updates need no file
manager.

## In-app updates

- **Automatic checks** — on launch the app looks for a newer release on GitHub
  Releases, at most once every 24 hours.
- **Floating prompt** — when a newer version exists, a dialog shows its version
  and notes with **Later** and **Update**. **Later** hides that version for 24
  hours; the next check is still throttled to once a day.
- **In-app download** — **Update** downloads the APK inside the app and shows
  progress. You can cancel a download.
- **Verification before install** — the download must match the published
  SHA-256 in `SHA256SUMS`, carry the expected package name, and be signed with
  the same certificate as the installed app. If any check fails, the update
  stops with an error instead of opening the installer.
- **System installer** — after verification the app hands the APK to Android's
  system installer. Android may ask you to allow installs from this app the
  first time.
- **Manage & Export** — a new Updates card shows the current version, a
  **Check for updates automatically** switch to turn checks off, and a
  **Check now** button. Manual checks still work when automatic checks are off.

The update check reads the public GitHub Releases feed. While this repository
stays private, that feed returns nothing, so the check cannot see new versions
until the releases are public.

### Upgrading from v0.3.0

v0.3.0 has no updater, so install v0.4.0 once by hand. After that, updates are
handled in-app.

### Moving from a debug build

Android will not install this release over a debug-signed build. Export a JSON
backup from the debug app first, uninstall it, install this APK, then restore
the backup.

## What's in this release

- **Daily entry moves** — long-press an entry and drag it to a new position in
  the same Time Slot or into another Time Slot on the same date; accessible move
  actions are available for those who cannot drag. The move is saved in backups
  and keeps the entry's activity, note, direction, value, and dimension.
- **Insights navigation** — step to previous and next date ranges with arrows
  for Today, Last 7 Days, and Last 30 Days; the dimension filter is kept while
  browsing ranges.
- **Updater UI** — the update dialog and the Updates card in Manage & Export,
  as described above.
- **Daily Account** — a zero-based energy ledger per day with Total Gain, Total
  Spend, and Net Balance, split into four Time Slots (Early Morning, Late
  Morning, Afternoon, Evening).
- **Entries** — log an Activity with an optional Situational Note, a Direction
  (Spend/Gain), an Energy Value from 1 to 100, and one Energy Dimension
  (Physical, Cognitive, Sensory, Social, Emotional, plus custom dimensions).
- **Activity Templates** — reusable blueprints that pre-fill direction, value,
  and dimension; pin your favourites for one-tap logging.
- **Check-in Reminders** — purely local notifications per Time Slot that
  automatically stay quiet when the slot already has entries.
- **Insights** — summary grid, Gain/Spend/Net trend chart, and breakdowns by
  dimension and time slot for today, the last 7 or 30 days, or a custom range.
- **Calendar history** — browse past days at a glance.
- **Export** — practitioner PDF report, CSV, and JSON backup/restore.
- **Two languages** — English and Italian.

## Privacy

- No account, no ads, no analytics, no trackers.
- All entries stay in a local Room database on your device.
- The only network access is the optional update check. It sends a request to
  GitHub; nothing is uploaded. Turning the automatic check off stops it, and
  **Check now** remains the only way to look for a release.

## Installation

- Requires **Android 8.0 or newer**.
- Download `empathie-energy-accounting-v0.4.0.apk`, allow installs from unknown
  sources when Android asks, and install.
- Verify the download against `SHA256SUMS` attached to this release.

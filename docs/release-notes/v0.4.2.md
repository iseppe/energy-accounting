# Energy Accounting v0.4.2

This patch fixes the notification and update-dialog issues reported after v0.4.1.

## Notifications

- The app now asks for notification permission on first open when a reminder is enabled, including after restoring a backup.
- If notifications are off, Manage & Export shows a warning with a shortcut to allow them.
- The status bar now shows the app's bolt mark instead of a plus sign; the expanded notification keeps the app icon.

## Update dialog

- The update prompt is now a bottom sheet.
- Release notes are formatted with headings, bold text, and bullet lists instead of raw Markdown.

## Upgrading

v0.4.1 can update itself: open **Manage & Export → Check now**, or wait for the launch check. v0.4.0 or older install this APK by hand.

## Installation

- Requires **Android 8.0 or newer**.
- Download `energy-accounting-v0.4.2.apk` attached to this release.
- Verify the download against `SHA256SUMS`.

# Energy Accounting v0.4.1

v0.4.1 is a private patch release. It fixes the launcher icon, finishes the
updater hardening that was merged after v0.4.0, and cleans up the user-visible
name to **Energy Accounting**.

## Launcher icon

- **Why the icon was missing** — v0.3.0 and v0.4.0 shipped an adaptive launcher
  icon whose vector paths used a compact SVG arc syntax. Android's path parser
  rejected them, so the icon could not be inflated and the launcher fell back to
  the default Android icon.
- **Normalized vectors** — the foreground and monochrome vectors now write every
  arc parameter explicitly. The Two-Hemispheres artwork renders with its slate,
  sage, amber, and paper palette; the design itself is unchanged.
- **Verified by drawing it** — a new instrumentation test draws the packaged
  application icon and asserts those four palette colors, and the release
  workflow now fails if the built APK does not expose an application icon.
- **If the old icon persists** — some launchers keep a cached icon. Reboot the
  phone or clear the launcher's cache once after installing; the new icon then
  appears.

## Updater hardening

Building on the in-app updater introduced in v0.4.0:

- **Clearer failures** — running out of storage is reported as a storage
  problem instead of a network error.
- **Specific download checks** — a file for a different app package and a file
  that cannot be read as an app now get their own messages, alongside the
  existing checksum and signature errors.
- **Guarded install settings** — opening the system screen that allows installs
  from this app is now guarded, so devices without that screen report the
  problem instead of crashing.
- **Reliable cancel** — cancelling a download updates the update state
  atomically, so a cancelled download cannot resurface as an active one.
- **Real verifier test** — instrumentation now exercises the APK verifier
  against real APKs rather than mocks.
- **Stable tests** — a flaky test was stabilized so the suite reports the same
  result on every run.
- **Release checks** — CI now builds the release APK and asserts the release
  certificate before publishing.
- **Polish** — UI, accessibility, and English/Italian copy fixes; the bundled
  Lucide icons now carry their ISC notice.

## README and branding

The README header is centered — icon, the title **Energy Accounting**, the
tagline, and the badges — and the old naming is gone from the remaining
user-visible surfaces: the app name, release titles, and release notes. The
Android package and signing identity are unchanged, so in-place updates keep
working.

## Upgrading from v0.4.0

This repository is private, so the in-app updater cannot see this release; the
GitHub Releases feed it reads returns nothing until the releases are public.
Install `energy-accounting-v0.4.1.apk` once by hand. It uses the same signing
key as v0.4.0, so it installs over v0.4.0 with no uninstall and no data
migration. Future in-app updates work once the releases are public.

The live updater test (download, verify, and install through the app) remains
deferred while the repository is private.

## Installation

- Requires **Android 8.0 or newer**.
- Download `energy-accounting-v0.4.1.apk` attached to this release, allow
  installs from unknown sources when Android asks, and install.
- Verify the download against `SHA256SUMS` attached to this release.

# Energy Accounting v0.4.3

This patch fixes the short-window update sheet and a few polish issues found in the v0.4.2 review. It also includes the v0.4.2 notification permission, status-bar icon, and update-dialog fixes.

## Update sheet

- **Later** and **Update** stay visible in landscape and split-screen; the release notes scroll instead.
- Inline code in release notes is rendered without backticks.
- The sheet can no longer be swiped away while a download or verification is running.

## Notification warning

- The warning card stacks its actions so the primary button is not squeezed off-screen.
- After notification permission is permanently denied, the card offers notification settings instead of a dead allow button.

## Upgrading

v0.4.2 can update itself: open **Manage & Export → Check now**, or wait for the launch check. Older versions install this APK by hand.

## Installation

- Requires **Android 8.0 or newer**.
- Download `energy-accounting-v0.4.3.apk` attached to this release.
- Verify the download against `SHA256SUMS`.
